The whole site is one file, `public/index.html` (inline CSS + one inline script, no build, no framework). It's a desktop with no top menu bar (that's the point of the site; see the critique doc on the desktop).

- **Dock** (`DOCK` array): aB menu icon (a periodic-table element tile: 42, script "aB", "altbryson"), Terminal, Calculator | phone projects | system tray: 3 Google Voice Tray icons, Weather, Bluetooth, Battery (vertical, 42%), Wi-Fi, Sound (volume slider, visual only; saved per browser), Spotlight, Settings, Clock. Items with `tray: true` hide from the dock at ≤1000px wide and show in a dark panel at the top of the aB menu instead; the clock always stays. Tray glyphs are fitted to one height by `TRAY_FIT` ([visual height, centre x, centre y, visual width] per icon; update it when a glyph is redrawn). Each tray slot is as wide as its glyph plus a fixed margin (`--w`), so the gaps between system icons are equal and render 20% larger via CSS scale. Icon size `--size` scales with the viewport up to macOS's 128px max; magnification is capped so the dock never leaves the screen; ≤1000px wide the dock scrolls sideways. The space windows keep clear of is tied to the dock's real size: CSS `--dock-h: calc(var(--size) + 40px)` and JS `dockH()` measures the dock's top, so windows, full screen and the default Baseless window never slide behind it.
- **Icons**: `ICONS` holds 100×100 SVG bodies; `IMG_ICONS` uses an app's real icon (budgetforecast, road) from `public/icons/`; Baseless is drawn from its favicon.svg parachute over a yellow sunset sky with distant ground. System-tray icons are flat white glyphs with no tile (`.app-icon.icon-*` list near the top of the CSS). The clock is a square tile with two-digit hours stacked over minutes (08 / 10); AM/PM and the date are in its label and popover.
- **Windows** (`openWindow`): draggable by titlebar (or any `[data-drag]` area), resizable from every edge (`RESIZE_DIRS`), green = full screen above the dock, yellow = minimize into the dock icon (state kept; reopening restores). `resizable: false` for Calculator.
- **Projects** (`PROJECTS`): Baseless Chat (`device: 'browser'`) is the desktop's web browser and opens automatically when the site loads (unless the URL hash names another project): it opens as a large, resizable window (up to 1280×860) running https://baseless.chat full size, with no phone frame or info panel, and Chrome-style tabs in the titlebar (`setupBrowserTabs`: + opens a tab, × closes, closing the last tab closes the window; each tab is its own iframe; baseless.chat's `reportPageToParent` posts `{type: 'baseless.chat.page', title, url}` to altbryson's origins only, and the tab shows that title, e.g. "zillow.com/homes/" or "baseless.chat" on its home page); baseless.chat's own site shows the page on the left and its chat on the right. Clicking a web app in the dock opens it straight into a new Baseless tab (`openInBaseless`); its phone-frame window is still reachable from Spotlight, Recent Items and #id links, and has an "Open in Baseless ↗" button: it opens the site as a new tab in the Baseless browser (https://baseless.chat/?url=site), opening or restoring that window first; non-framable links (GitHub for Google Voice Tray, LinkedIn/X/GitHub on the desktop) still open real browser tabs. Phone apps load live in an iframe inside a phone frame at a true 375px viewport (no scaling), screen height ≤667px; the screenshot `public/<id>.png` shows behind the iframe while it loads. `stage: 'alpha' | 'beta'` shows α/β in the same red badge style as unread counts.
- **Desktop**: `DESK_DOCS` items (Built with Claude, resume placeholder, The Menu Bar Problem critique, Legal Disclaimer, "SketchUp Samples.skp" (coming soon), plus link shortcuts for LinkedIn, X @brysonwf, X @brysonf and GitHub) sit in a grid that fills from the top-right column by column and wraps on short screens. Items can be dragged; they snap to the nearest cell (swapping with the occupant) and the layout is saved per browser (`deskLayout` in localStorage). Documents: click selects, double-click opens (tap on touch). Links open their site directly in a new tab on one click. The Trash is the last grid item, just below the other icons.
- **Google Voice Tray demo**: the 3 tray icons (circle = Messages, triangle = Voicemail, square = Chat) are grey at 0 unread, green when unread, exactly like the real app. Clicking opens a 375×667-ish drawer bottom-right with demo screens (fictional names, 555 numbers); right-click gives the app's real tray menu. Every screen has a "Get it on GitHub" bar → github.com/brysonwf/googlevoicetray (no releases published yet).
- **Fixed fake status**: battery is always 42% not charging, Wi-Fi 2 of 3 bars, Bluetooth lists "MX Master" connected, weather is always Carolina Beach, NC (Open-Meteo, no visitor location).
- `screenshot.js` (Puppeteer) re-captures the phone screenshots at 390×844: `node screenshot.js`.
